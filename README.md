# Random Task Generator 🎲

**Автор:** Олейников Матвей

## Описание проекта

Random Task Generator — это десктопное приложение на Python с графическим интерфейсом, которое помогает генерировать случайные задачи для продуктивности. Приложение позволяет:

- Генерировать случайные задачи из предопределённого списка
- Фильтровать задачи по типу (учёба, спорт, работа)
- Добавлять собственные задачи
- Сохранять историю сгенерированных задач в JSON
- Загружать историю при следующем запуске
- Экспортировать историю в отдельный JSON файл
